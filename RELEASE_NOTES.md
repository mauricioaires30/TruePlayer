## Novidades do TruePlayer 1.6.1

- **Git com repositório que já tem arquivos:** agora dá para ligar a pasta a um repositório do GitHub que já existe. O que só estiver no GitHub vem para a pasta, e se um arquivo for diferente vale o da pasta (a versão antiga fica no histórico). Nada é sobrescrito nem forçado.
- **Downloads não se perdem:** a fila fica guardada. Se o Android fechar o app no meio, o que faltava continua na próxima vez que você abrir, inclusive playlists, na ordem original.
- **Novidades legíveis:** o texto das atualizações aparece formatado, sem os símbolos do Markdown.
- **Textos mais curtos** nas configurações e nos avisos.
